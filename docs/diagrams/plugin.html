speckit-overview · add-on for GitHub Spec Kit

What one command installs

A Spec Kit preset and extension, checked before Spec Kit's own installer puts them in place.

Install
# in an existing Spec Kit project
$npx speckit-overview
# or start a new one
$npx speckit-overview init my-app --integration claude

01Verify

Both bundled zips must match the SHA-256 recorded at build time. On a mismatch, nothing is installed.

02Serve

A throwaway server on 127.0.0.1, random port and 256-bit path, closed when done.

03Install

specify preset add and specify extension add fetch from it, with Spec Kit's archive checks.
