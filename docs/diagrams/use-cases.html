speckit-overview · add-on for GitHub Spec Kit

Five gaps it closes around the feature loop

Spec Kit takes one feature from spec to code. Everything above and after that feature was up to you.

Without itWith speckit-overview
01

Specs get written before anyone has pinned down why the product exists.

/speckit-overview interviews you one question at a time: pitch, users, core loop, non-goals, why this approach. Nothing is written until you approve the draft.specs/mission.md
02

A whole product gets squeezed into a single feature spec.

It splits the work into ordered phases, each one Spec Kit feature. /speckit-specify picks up the next unchecked phase.specs/roadmap.md
03

The constitution is guessed from whatever the README says.

/speckit-constitution derives its principles, constraints and workflow rules from your mission, roadmap, stack and model notes..specify/memory/constitution.md
04

The roadmap is out of date a week after it was written.

After /speckit-implement, a hook ticks the phase off, and only once every task in tasks.md is done.after_implement hook
05

Every task runs on the same model and effort, trivial or not.

Each recurring task type gets a model or effort tier, with the reason written next to it.specs/implementation.md
Works with the stock specify CLI, Spec Kit 1.0.4+
